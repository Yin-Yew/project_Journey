⚙️ หลักการทำงานของระบบ
1. ส่วนแสดงผล (Frontend)
หน้าเว็บอยู่ในโฟลเดอร์ public/ โดย HTML กำหนดโครงสร้างของแต่ละหน้า ส่วน CSS
กำหนดสี การจัดวาง และธีม และ JavaScript ทำหน้าที่ตอบสนองต่อการกระทำของผู้ใช้ เช่น
การเลือกธีม การเปลี่ยนทริป และการจัดการข้อมูล Planner/Places
2. การเลือกธีม
1. ผู้ใช้เปิดหน้า settings.html
2. เลือกธีมที่ต้องการ เช่น Cosmic Journey
3. ฟังก์ชันที่ผูกกับตัวเลือกธีมจะบันทึกการเลือกและนำธีมไปใช้
4. CSS เลือกชุดสีตามค่าธีมที่กำหนดไว้
5. ผู้ใช้สามารถเปลี่ยนตัวเลือกแอนิเมชันได้จากหน้าเดียวกัน
ค่าการตั้งค่าระบุว่าเก็บไว้บนอุปกรณ์
จึงควรทดสอบบนเบราว์เซอร์เดียวกันเมื่อตรวจสอบการคงค่าหลังรีเฟรช
3. การทำงานของ Planner
1. ผู้ใช้เลือกทริปที่ต้องการ
2. ระบบแสดงส่วน Planner ของทริปนั้น
3. กิจกรรมถูกจัดตามวันและข้อมูลเวลา
4. ผู้ใช้สามารถจัดการรายการกิจกรรมผ่านส่วนควบคุมของหน้า
5. จำนวนกิจกรรมสามารถนำไปแสดงในภาพรวมทริปได้
4. การทำงานของ Places
1. ผู้ใช้เปิดหน้า Places และเลือกทริป
2. ระบบแสดงรายการสถานที่ของทริปนั้น
3. ข้อมูลสถานที่อาจประกอบด้วยชื่อ ประเภท คำอธิบาย และรูปภาพ
4. มีปุ่มโหวตให้ผู้ใช้โต้ตอบกับสถานที่
ข้อจำกัดด้านข้อมูล: README ที่อยู่ใน ZIP ระบุว่า Planner, Places
และคะแนนโหวตในชุดเดโมนี้ใช้ localStorage ของเบราว์เซอร์
ดังนั้นข้อมูลอาจไม่ซิงค์ข้ามอุปกรณ์หรือข้ามเบราว์เซอร์
และไม่ควรถือว่าเป็นระบบโหวตร่วมกันแบบหลายผู้ใช้ที่มีการตรวจสอบตัวตนจากฐานข้อมูล
5. Backend และฐานข้อมูล
ใน ZIP มีโฟลเดอร์ server/ และ database/
ซึ่งประกอบด้วยไฟล์เซิร์ฟเวอร์และสคีมาฐานข้อมูล อย่างไรก็ตาม
ฟีเจอร์แต่ละส่วนอาจใช้แหล่งเก็บข้อมูลต่างกัน
ต้องตรวจสอบการเชื่อมต่อและโค้ดของแต่ละฟีเจอร์ก่อนสรุปว่าข้อมูลทั้งหมดบันทึกลง MySQL
📂 ไฟล์สำคัญที่เกี่ยวข้อง
  ไฟล์                                 หน้าที่โดยสรุป
  public/settings.html              หน้าเลือกธีมและตั้งค่าแอนิเมชัน

  public/css/style.css              สไตล์หลักของเว็บไซต์ รวมถึงชุดสีของธีม

  public/js/script.js               JavaScript
                                      หลักสำหรับการทำงานร่วมกันของหน้าเว็บและข้อมูลทริป

  public/planner.html               หน้า Travel Planner

  public/places.html                หน้าสถานที่ท่องเที่ยว

  public/css/planner-places.css     สไตล์ของส่วน Planner และ Places

  public/js/planner-places.js       การทำงานที่เกี่ยวข้องกับกิจกรรมและสถานที่

  public/trip-detail.html           หน้ารายละเอียดและภาพรวมของทริป

  public/expenses.html              หน้าค่าใช้จ่าย

  public/checklist.html             หน้ารายการสิ่งของที่ต้องเตรียม

  public/memories.html              หน้าความทรงจำและรูปภาพ

  server/app.js                     จุดเริ่มต้นของ Backend ในชุดโปรเจกต์

  server/database.js                ส่วนเชื่อมต่อฐานข้อมูล
  database/schema.sql               โครงสร้างฐานข้อมูล
💻 เทคโนโลยีที่ใช้
  เทคโนโลยี               บทบาท
  HTML5                  กำหนดโครงสร้างหน้าเว็บไซต์
  CSS3                   ออกแบบหน้าตา การจัดวาง และธีม Cosmic Journey
  JavaScript             จัดการเหตุการณ์และการทำงานของฟีเจอร์หน้าเว็บ
  Node.js / Express.js   ใช้ในส่วน Backend ของโปรเจกต์
  MySQL                  ฐานข้อมูลที่มีสคีมาประกอบในโปรเจกต์
  Git / GitHub           ควบคุมเวอร์ชันและเก็บซอร์สโค้ด
⚠️ ข้อจำกัดที่ควรทราบ
- การเลือกธีมและแอนิเมชันระบุว่าเก็บค่าบนอุปกรณ์
  จึงไม่ใช่การซิงค์การตั้งค่าระหว่างผู้ใช้โดยอัตโนมัติ
- README ภายใน ZIP ระบุว่า Planner, Places และคะแนนโหวตของชุดเดโมใช้
  localStorage จึงเหมาะกับการสาธิตในเบราว์เซอร์
  และไม่ใช่ข้อมูลกลางสำหรับหลายอุปกรณ์
- การมีไฟล์ Backend และฐานข้อมูลอยู่ในโปรเจกต์
  ไม่ได้ยืนยันว่าทุกฟีเจอร์เชื่อมต่อฐานข้อมูลจริงแล้ว
- ยังไม่ได้ยืนยันจากการเปรียบเทียบกับ Branch feature/planner-places
  ว่าไฟล์ใดเป็นไฟล์ใหม่หรือถูกแก้ไขจากเวอร์ชันเดิม
- ก่อนนำขึ้นระบบจริง ควรทดสอบการบันทึกข้อมูล การเข้าสู่ระบบ สิทธิ์ผู้ใช้
  และการทำงานบนอุปกรณ์หลายเครื่อง
